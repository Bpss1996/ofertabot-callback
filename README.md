# Garimpo Certo — páginas para TikTok

1. No repositório `Bpss1996/Bpss`, clique em **uploading an existing file**.
2. Envie `index.html`, `termos.html` e `privacidade.html` desta pasta.
3. Quando o TikTok baixar o arquivo de assinatura, envie-o para esta mesma raiz, sem renomeá-lo.
4. Em **Settings > Pages**, selecione **Deploy from a branch**, branch `main` e pasta `/ (root)`.
5. A URL publicada será `https://bpss1996.github.io/Bpss/`.

Use no TikTok:

- Termos: `https://bpss1996.github.io/Bpss/termos.html`
- Privacidade: `https://bpss1996.github.io/Bpss/privacidade.html`
- Verificação por prefixo: `https://bpss1996.github.io/Bpss/`
